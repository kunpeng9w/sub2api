# 真实联调申请模板（未获批准，不得执行）

模拟验证完成不代表真实代理出口已经验收。本次开发不启动应用或调度器来做真实检测。

发起批准前，先用只读配置确定并向用户展示以下内容，不得使用默认账号或临时替换代理：

| 必填项 | 内容 |
| --- | --- |
| 待测提交与构建产物 SHA256 | 待填写 |
| 监控 ID、账号 ID、账号类型 | 待填写，不包含令牌 |
| 当前绑定代理 ID、名称及协议 | 待填写，不包含代理密码 |
| 目标地址、HTTP 方法和用途 | 逐项填写，包括必要的凭据刷新 |
| 每个目标的最大请求次数 | 待填写；禁止自动增加次数 |
| 是否消耗模型额度 | 区分纯配额与探活 |
| 是否包含 HEAD 延迟检测 | 明确填写；不作为模型请求隐含执行 |
| 失败后的处理 | 停止，不自动补测其他模型或代理 |

批准后仅在获批范围执行：

1. 先用隔离测试配置验证无代理、停用代理和连接失败均不会转为直连；不得停用正在承载业务的生产代理。
2. 再执行获批的单次配额查询或探活，核对代理选择日志、代理端连接记录和响应；不追加出口 IP/地理位置查询。
3. 如需确认实际公网 IP，应另列验证方法及目标请求并取得批准。代理标识日志仅能证明应用选用的代理，不能单独证明代理后的公网 NAT 地址。
4. 记录实际请求次数、脱敏结果、异常及停止原因。任何扩大范围、切换代理、增测模型或重试都需要重新确认。

部署、重启或启用线上自动检测属于另一次操作，不包含在真实查询测试批准中。
