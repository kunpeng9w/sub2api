# 渠道监控手动检测、用户授权和额度估算

本次只交付源码、迁移及 GitHub Actions 验证产物，不部署、不重启服务、不修改 DNS/Mihomo/防火墙，不调用真实上游或真实代理。

## 行为

- 新建监控默认纯手动、仅管理员可见；存量监控保留原自动检测配置及所有用户可见性。迁移不发请求。
- 创建、编辑、复制及服务启动不立即检测；自动模式等待一个周期。复制仍为停用状态，并重置为纯手动、仅管理员可见。
- 可见范围支持所有用户、指定多名用户、仅管理员。授权控制列表、详情与手动检测；用户检测结果在获授权用户间共享。用户不能覆盖目标或代理配置。
- 用户/管理员手动检测和定时检测共用并发上限（5），Redis 跨实例租约互斥。锁失效阻止执行；手动检测每用户每监控冷却 60 秒。409 表示执行中或容量满，429 返回 Retry-After。
- 关联账号时只使用该账号的当前代理；独立探活使用显式代理。出口缺失、失效、变更或连接失败时禁止直连及备用出口。存量缺代理监控保留历史，管理端提示不可用。
- 监控请求禁止重定向；OpenAI 配额不追加模型回退、重置额度查询或身份恢复；Antigravity 不追加订阅查询和备用端点请求；出口审计不额外查询出口 IP。
- DNS 和防内网访问校验沿用现有策略，HTTP/HTTPS/SOCKS 业务请求经绑定代理。本次应用改动不负责改变代理服务内部的路由规则。
- 账号页与监控页复用后端估算；支持 Anthropic 5h/7d/Sonnet/Fable 和 OpenAI 5h/7d。按实际模型、各自窗口及采样时间统计本地账号费用。
- 总额度 = 已用费用 / 已用比例；剩余 = 总额度 × max(0, 1 - 已用比例)。过期、缺失采样时间或无有效费用时不估算。历史未知时间不会伪装成页面读取时间。
- 新的被动请求采样会分别记录各窗口时间；旧快照无需补发查询。显示额度仍受系统额度开关控制，普通用户不接收账号费用明细或上游原始错误。

## 验证方式

优先使用现有 backend-ci.yml / ops-ci.yml，并增加 channel-monitor-ci.yml 跑专项回归、远程 Ent/Wire 生成和构建。测试使用假凭据、模拟 DNS、传输层和回环代理。测试阶段的网络包装器拒绝测试用户建立公网连接，只允许回环和 Docker 测试网络；构建依赖安装在隔离测试之前完成。

所有编译、生成代码、测试、类型检查、Lint、构建均在 GitHub Actions 执行。本机只编辑、检查 diff 和读取远程日志。对应提交、Actions 结果及 artifacts 在 VALIDATION.md 记录；真实联调必须另按 LIVE-TEST-CHECKLIST.md 取得批准。
