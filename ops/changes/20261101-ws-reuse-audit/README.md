连接池审计此前直接记录租约借出时的 `Reused()`，因此同一租约连续多轮请求一直显示首次借出时的值。现在每个租约额外记录是否已开始过请求轮次：新连接首轮为 false，后续为 true；从连接池借到已有连接时，首轮即为 true。

状态按租约保存，不依赖 `turn_id` 大小。会话进行到第 9 轮才换到新连接时，新连接首轮仍为 false；HTTP-to-WS 路径的重试编号从 0 开始或重复也能正确记录。`Reused()` 原有的连接池获取指标语义不变，拨号、路由、认证、请求内容和数据库结构不变。

`TestEgressAuditPoolConnectionReuseAcrossTurns` 覆盖新连接多轮、借到已有连接、会话中途换新连接，以及重复/从零开始的重试编号，并核对 started/completed 字段一致、attempt 独立和原获取指标保持不变。完整集成、常规 CI、安全扫描和嵌入前端构建通过 GitHub Actions 执行，本机不编译应用。
